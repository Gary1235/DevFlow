# 簡化任務流程

此頁記錄上一版的計畫確認流程，保留在進階操作中。新對話預設使用 [單一對話與主 AI](conversation-agent.md)，不再要求先選主管／實作／驗收模型。

1. 開啟「對話與計畫」，選專案，直接傳送需求。對話名稱沿用第一個問題的摘要，不用先填計畫。
2. 輸入框旁可切換 AI、模型及支援的推理程度；下一則訊息使用新選擇，同一對話保留歷史。
3. 討論定案後按「整理實作計畫」。右側顯示完整計畫與驗收條件。可以繼續聊天調整，再按「更新實作計畫」。未決問題與後續新增的需求必須先整理進最新計畫。
4. 按「選模型並開始」，選主管與實作模型；驗收 AI 選填。按「核准計畫並開始」才建立並排隊執行，不會因聊天回答「好」就啟動。主管預設目前對話模型，實作及驗收沿用同一專案上次選擇，可自由更換。
5. 系統依專案已儲存的所有驗證設定執行建置／測試，沒有多個設定時沿用既有預設。前後端目錄、指令及依賴準備只需在專案設定一次。缺少依賴或驗證環境錯誤仍需修正設定，額外安裝不會自動獲准。
6. 一般編譯／測試失敗交主管判斷；計畫範圍內指派實作 AI 修正，再驗證。若選驗收 AI，也會檢查成果，要求修改時由主管協調。連續三次相同問題／無進展，或主管要求人工決策，會保存成果並暫停。這是重新執行修正，不是恢復原 CLI 對話。
7. 全部通過後顯示待成果審核，提示開啟預覽進行人工測試。建置成功不等於功能驗收成功；確認差異及功能後，仍由使用者核准合併。

主管只能處理核准計畫內的實作判斷，不會代替人核准工具額外權限、擴充需求或削弱測試。原有唯讀討論、指定任務工作副本、操作邊界與 CLI 原生限制保留。CLI 中斷直接回報，不以此流程自動核准或重新執行。

舊任務與自訂流程保留。簡化任務的流程詳細設定收在「進階執行詳情與流程設定」；需求對話仍可從任務頁返回。此版本只變更本地網站及 API／Worker，未發行桌面安裝包。
